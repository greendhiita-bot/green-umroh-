# Green

Aplikasi tabungan umroh Rp 28 juta dalam 12 bulan, ditemani maskot Green.

Buka di HP lewat GitHub Pages, lalu pasang ke layar utama:
- Android (Chrome): menu ⋮ → **Instal aplikasi**
- iPhone (Safari): **Bagikan** → **Tambah ke Layar Utama**

Data tabungan tersimpan di HP masing-masing (tidak dikirim ke server). Gunakan **Simpan cadangan** di Pengaturan untuk mencadangkan.
